# Besbasa | Simply

**Summarize long texts in a simple and quick way — paste text, open a TXT or PDF file, or take a photo of the page. Get a few key points and a simple explanation. Fully offline.**

## About the App

**Besbasa** is a text summarization application that works entirely offline.

The app helps users understand long texts more easily and quickly, whether they are lessons, articles, or reports, by extracting the most important information and presenting it in a concise and clear way.

The app supports both Arabic and English, and protects user privacy because data processing takes place directly on the device, without the need for an external server or an internet connection.

## Ways to Use the App

Users can start summarizing in several ways:

- **Paste Text:** Copy any text and paste it into the app.
- **Open Files:** Select TXT, PDF, or other supported text files.
- **Use the Camera:** Take a photo of a page from a book or a sheet of paper and convert its content into text that can be summarized.

## Features

- Summarize long texts in a simple and quick way.
- Extract the key points from the content.
- Provide a simple explanation that helps users understand the main idea.
- Support both Arabic and English.
- Work entirely offline.
- Save previous summaries and access them easily.
- Search within the summary history.
- Support dark and light modes.
